# to-hoot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build to-hoot, a personal productivity and time-tracking app that runs on Linux desktop and Android from one codebase, syncs through a private GitHub repo, reads and writes Google Calendar, and exposes itself to Claude over MCP.

**Architecture:** An npm-workspaces monorepo. `packages/core` is pure TypeScript holding the models, an append-only event log, the merge/replay engine and the wall-clock tick, with no DOM dependency. `packages/ui` is the entire React application. `apps/desktop` (Tauri) and `apps/mobile` (Capacitor) are thin shells supplying a `Platform` adapter. `apps/mcp` and `apps/worker` expose the same tool implementations over stdio and HTTPS. Sync is an append-only event log in a private GitHub repo, committed through the Git Data API.

**Tech Stack:** TypeScript 5.7, React 19, Vite 6, Vitest, Tauri 2.11, Capacitor 8.5, Cloudflare Workers, `@modelcontextprotocol/server` 2.0, Google Apps Script, Playwright, WebdriverIO, Maestro.

**Spec:** `docs/superpowers/specs/2026-08-23-to-hoot-design.md`

## Global Constraints

Every task's requirements implicitly include this section.

- **Package manager is npm workspaces.** Never pnpm. Capacitor's CLI breaks on pnpm's symlinked `node_modules` (ionic-team/capacitor#865, open).
- **Node 22+ and JDK 21** are required by Capacitor 8. Both verified present.
- **Zero cost is a hard constraint.** No service that requires a credit card. No paid tier. The WebDriver provider is pinned to `embedded` (`crabnebula` requires a subscription) and `maestro cloud` is never invoked.
- **Nothing is hardcoded to one user's accounts.** No email address, repo name, token or URL may appear as a literal in source. All are runtime settings.
- **Fonts are SIL OFL only** (Instrument Sans, Newsreader, JetBrains Mono), self-hosted, subsetted, renamed after subsetting, each shipping its `OFL.txt`.
- **Writing style, enforced in all code comments, docs, commit messages, UI copy and the site:** no emojis anywhere. No em dashes or en dashes as sentence punctuation; use a comma, colon, parentheses or a new sentence. Hyphens in compound words and numeric ranges are fine. No marketing tone, no "isn't just X, it's Y", no rule-of-three padding.
- **Commit messages describe the change only.** Never add `Claude-Session:`, `Co-Authored-By:`, `claude.ai/code` links, or "Generated with" notices. A global `commit-msg` hook rejects them. Never bypass with `--no-verify`.
- **Git identity** resolves from the global config (`danieltyukov <60662998+danieltyukov@users.noreply.github.com>`). Never set a per-repo `user.email` override.
- **`force: true` is never passed to the GitHub refs API**, anywhere, under any condition.
- **`legacy: 'stateless'`** on the MCP handler. Never `legacy: 'reject'`; Claude's remote infrastructure is legacy-era.
- **Design tokens:** accent `#d97757` dark / `#c2603f` light. Exactly two radii, 6px controls and 10px panels. Motion 100/200/320ms at `cubic-bezier(.165,.84,.44,1)`, no springs. Base font size 15px.
- **Every icon-only control needs an `aria-label`.** Maestro reads the accessibility tree; an unlabelled control is untestable.
- **`timeSpent` is derived and never written directly.** `timeSpentOnDay` is the storage.

- [ ] **Step 3: Implement**

`dayStr` must use local calendar fields, not `toISOString()`, which would return UTC and shift the day for anyone not on UTC.

```ts
export function dayStr(ts: number, offsetMs = 0): string {
  const d = new Date(ts - offsetMs);
  const p = (n: number) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`;
}
```

ULID: 10 chars of base32 time + 16 chars of base32 randomness, with a monotonic counter so two calls in the same millisecond still sort.


A NaN delta is not hypothetical: it serialises to `null` in JSON and silently zeroes a whole day of tracked time.

- [ ] **Step 2: Run, confirm failure**

Run: `npm test -- tick`

- [ ] **Step 3: Implement**

```ts
export class Ticker {
  private last: number;
  constructor(private nowFn: () => number = Date.now) { this.last = nowFn(); }
  consume() {
    const now = this.nowFn();
    let delta = now - this.last;
    if (!Number.isFinite(delta) || delta < 0) delta = 0;
    this.last = Number.isFinite(now) ? now : this.last;
    return { delta, day: dayStr(Number.isFinite(now) ? now : this.last), now };
  }
  reset() { this.last = this.nowFn(); }
}
```
